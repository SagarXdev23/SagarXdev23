### 🔗 SyncSpace

**A real-time collaborative workspace for teams** combining project management, Kanban boards, team chat, file sharing, notifications, and activity tracking in one platform.

**Highlights:**

- 🔐 JWT authentication with refresh-token rotation and session reuse detection
- 👥 Workspace roles and **RBAC** — OWNER / ADMIN / MEMBER
- 📋 Projects, tasks, Kanban boards, comments, and activity feeds
- ⚡ Real-time chat, typing indicators, presence, and notifications with **Socket.io**
- 🚀 **Redis** caching and rate limiting with graceful fallback
- ☁️ **Cloudinary** file and profile-image uploads
- 🗄️ **MongoDB Atlas** as the application source of truth
- 🎨 **React 18 + Vite + Redux Toolkit + Tailwind CSS**
